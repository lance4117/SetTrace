# 休息提醒与剩余组跳过

## 训练状态

组分为待完成、已完成、已跳过。完成两组后跳过两组仍保留目标四组，
历史摘要显示“2 / 4 组完成”；跳过不记录完成时间，不增加统计。
明确修改本次目标组数是另一种操作。跳过只作用于已有完成组的当前动作，
取消当前组间休息并直接进入下一待练动作，不开启动作间休息。

跳过确认和撤销确认都固定对象与训练基线，旧确认不覆盖最新进度。
独立撤销最近跳过按持久化批次恢复，保留后续已完成组与顺序；
撤销上一组只处理真实完成。含跳过组的动作先恢复后才能编辑配置。

## 提醒事件与输出

SQLite v6 是训练与提醒的唯一状态源。每次休息关联独立事件，原始 `due_at`
保持不变；`revision` 使旧回调失效，`delivery_sequence` 原子领取每一轮。
原生接收器支持 v4/v5/v6，不迁移数据库、不启动 Flutter 引擎、不写训练进度。

| 场景 | 行为 |
| --- | --- |
| 非零休息到期 | 首次领取；前台显示一个居中弹窗与 50% 暗色遮罩，后台／锁屏显示通知 |
| 等待确认 | 默认每 10 秒重复声音与两次短振动；可选 15／30／60 秒或关闭重复 |
| 重复到达 | 复用弹窗与同 ID 通知；按实际处理时间安排下一轮，不补发漏掉的次数 |
| 确认／页内停止 | 先保存确认，再取消 Alarm、通知和当前音频／振动；不完成组 |
| Android 返回 | 只收起弹窗，页内停止入口保留；同进程后续轮次不重开弹窗 |
| 编辑／面板／其他弹窗 | 声音继续，提醒弹窗等已有界面关闭后复核再显示 |
| 推进、取消或关闭提醒 | 训练事务先使旧提醒失效，提交后清理系统输出；旧回调不能复活 |
| 首次回调迟到超过 30 秒 | 过期；此边界不用于已有效投递的重复轮次 |
| 进程恢复／回前台 | 未首次投递的已到期事件过期；有效待确认事件只安排未来一轮，不立即补响 |

确认、偏好保存失败时保留原状态并提供重试。调度失败单独提示，训练记录与
绝对截止仍有效。只在成功返回通知所属训练页后确认对应事件；旧通知不停止
后来的休息，失效会话不打开另一场训练。冷启动等待欢迎说明与导航就绪。

## 设置、音频与系统能力

总开关默认开启，首次真正休息才解释通知权限；拒绝后不逐组询问。
关闭总开关收起子项、保留配置并取消当前事件；重新开启只安排未来有效休息。
间隔仍采用选择草稿与明确保存，试听不改变偏好、不通知、不振动、不重复。
运行时统一使用系统通知音，不再访问 APK raw 音频。历史 sound_id 三种合法值仅用于兼容，修改振动或间隔不重置它。
前台实际提醒与试听共用一个可观察单次播放器；试听不能中断真实提醒，离页停止，每段最长 10 秒。
播放器创建、准备、开始、完成、异步错误与停止各有有限诊断，失败不改变训练提交或领取结果。
后台声音完全交给系统通知，无应用额外叠播。

Android 8+ 使用 `settrace_rest_system_v1_0`／`_1` 两个稳定振动变体。
新装使用符号型系统默认通知 URI，系统单独为通道选择的声音优先。
串行迁移继承静音、封禁、低重要性、禁振和可读取的自选音；旧应用自带 URI 换为系统默认音。
目标已存在且无法继承更严格限制时抑制受限输出，提供系统设置入口，不删除重建、不生成第三通道。
平台状态每次重读，明确在系统解除限制后可恢复；身份不明的多个旧通道保守受限。
迁移标记只存版本、自有通道身份及限制标志，不存用户声音 URI，不纳入备份／ZIP。
设置展示实际有限状态，独立试听和系统设置可重试；系统设置不可打开时回退应用通知设置。
前台遵守静音、音量、勿扰与通道限制；试听不代表后台送达能力。
Android 13+ 通知需 POST_NOTIFICATIONS，振动使用 VIBRATE；不申请绕过勿扰权限。

AlarmManager 每次只安排下一轮。准时能力不足时降级非精确调度；Doze、系统
通知冷却及厂商限制可能明显拉长间隔，不承诺后台严格每 10 秒。通知权限不可用
时保留待确认状态，不持续进行无效后台唤醒；回前台重新核对。强行停止、重启
与厂商强制限制不保证送达。记录领取先于输出，进程若在两者之间终止可能漏响。

## 迁移与验证

v1/v2/v3 顺序升级至 v4，保留原总开关、训练、历史、快照、组和休息截止。
旧 v3 consumed 转为已确认，不恢复重复；旧无轮次 Intent 被新版接收器拒绝。
不删库降版，回退需兼容 v4。
