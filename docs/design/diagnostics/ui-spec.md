## 1. 目标与范围

普通用户应能理解记录状态、遇到问题时导出文件、按需协助复现。页面不展示日志等级、SQL、调用栈、内部错误码、原始事件列表和技术统计看板。

用户已确认最新设计并要求用于后续开发；当前已接入日志实现、应用界面与OpenSpec变更。已确认草图保持不变；真实界面与平台边界见[实施验收](../../qa/local-diagnostics-acceptance.md)。

当前 UI 设计默认值：常规本机记录默认开启、最多7×24小时且日志不超过20 MiB、临时详细诊断最长30分钟且重启关闭、ZIP主动导出到公共Download、不自动上传。上述值作为当前界面文案和状态设计的统一输入；后续技术规划若需调整，须说明影响并同步本文与草图，不由实现静默改变。存储预算分配、日志字段、写入器及异常捕获机制仍属于后续日志技术设计。

依据：[主设计入口](../README.md)、[主规范 §14](../SetTrace_UI_Design_System_and_Flutter_Spec.md)、[页面清单](../screens-and-states.md)、[INT-13](../interaction-spec.md)、[LOGUI-01–12](../acceptance-checklist.md)、[既有备份规范](../backup/backup-ui-spec.md)；现有 `app-experience`、`data-backup` 规格及 SettingsPage、AppColors 的职责。沿用 C01/C02/C04、INT-10/11、CMP-01/02/04/05、VIS-01–05、ADAPT-01–07。本文件的 L/LD/LE 为诊断增量编号，已接入主设计索引，不重用或替换既有编号，也不表示业务主规格已更新。

## 2. 导航与布局

```text
Settings / Data
  +--> Backup and restore (existing)
  +--> Diagnostics and logs [L01]
         +--> Export details [L02] --> Progress [L03] --> Saved [L04]
         |                                            +--> Partial [L06]
         +--> Temporary detailed logging [L05]
         +--> Logging and privacy [L08]
         +--> Clear confirmation [LD01]

Startup error [L07] --> Export details --> Progress --> Result
```

一级导航保留计划、记录、设置。入口增加在现有数据卡片内，备份与恢复之后、关于之前；与现有文字导航行一致，不加左侧装饰图标。已有设置顺序和功能保持，数据分区不再依赖备份回调是否可用。

深层任务页使用返回，无一级底部导航。回设置保留滚动与触发焦点；临时详细诊断页返回日志主页。导出成功完成返回来路页面，启动故障导出完成返回故障页，不跳入尚未初始化的正常首页。

每个任务页一个主操作。底部主操作区与正文滚动分离，预留实际安全区。导出期间休息截止、有效提醒与训练保持原语义，不结束或保存训练。

## 4. 主页面交互

开关最小触控目标48×48 dp，行内说明明确仅本机保存。正常点击保存成功后更新；提交中防重复。关闭记录不顺带删除旧日志。关闭常规记录同时停止临时详细记录；再次启用只恢复普通记录，不能复活旧详细期限。

详细诊断入口在常规记录关闭时仍可查看说明，但主按钮禁用，并明确“请先在上一页开启本机诊断记录”；不暗中更改总开关。开启或关闭失败时保持真实有效状态，错误就地显示可重试。

“已保存的日志”表示实际可读取范围，不等于连续覆盖，也不保证七天完整。存在缺口时显示“部分时段缺少日志，导出包会说明”，不能仅用最早与最晚时间掩盖缺失。读取失败与无日志必须分开。

容量条是日志空间占用，不是应用健康评分；读屏为“已用3.8 MiB，上限20 MiB”。达到上限后正常清理无需告警；清理或写入失败才显示受限反馈。

主页不展示错误总数，以免正常拒绝或已处理问题造成误解；技术摘要留在诊断包。保存策略首版只读，不增加保留天数和容量调参入口。

## 5. 导出与返回

L02显示截至最近采集时可用范围，实际固定范围在导出开始时记录；结果对应实际截止，不宣称包含生成期间的新操作。信息说明常驻，不反复增加确认弹窗或强制勾选同意。

L03显示完成、处理中和等待三个文字状态。可辅以静态序号／勾号和不定进度，减少动态效果时保留文字。读屏仅在阶段变化播报完整短句，不高频播报。

返回语义：L02返回不开始导出；L03系统返回与“取消导出”进入相同取消流程；可取消阶段立即响应取消意图。文件发布的短临界阶段若已不可取消，应显示“正在完成文件保存…”并等待真实结果，不能清理已经成功交付的文件后报告取消。退出进程后也不能根据旧进度页面猜测成功，重启按持久结果核查。

保存成功以真实发布且核验的文件为依据，文件名完整换行可选中复制；不增加默认分享、邮件上传或应用内反馈网络请求。公共文件不会被本机日志自动清理，也不承诺外部文件永久存在。

部分采集失败但ZIP有效时使用L06。全部必要内容都无法采集或ZIP无法构建则使用LE01，不制造空成功。

## 6. 错误文案与恢复

| 情况 | 推荐文字 | 操作 |
| --- | --- | --- |
| 空间不足 | 未能保存诊断包。下载目录所在存储空间不足，请腾出空间后重试。 | 重试保存／返回 |
| Android旧版本权限被拒绝 | 未获得下载目录写入权限，文件尚未保存。 | 适用时重新授权；永久拒绝提供应用设置；返回 |
| 存储不可用 | 暂时无法写入下载目录，文件尚未保存。 | 重试保存／返回 |
| 结果无法核实 | 暂时无法确认文件是否保存完成，请先检查下载目录。 | 重新核查／返回；不直接重复创建 |
| 局部信息缺失 | 已保存，部分信息不可用。 | 显示已导出内容与真实缺失原因；完成 |
| 开关保存失败 | 未能保存设置，仍保持原来的记录状态。 | 就地重试 |
| 清空部分失败 | 部分日志未能清空，请重试。 | 刷新真实范围和大小；重试清空 |

不能把日志异常提示成“训练数据未保存”，也不能在未知时承诺“所有记录完整”。权限窗口、设置和文件管理器外观由Android决定。

## 7. 清空与隐私说明

LD01标题“清空本机日志？”；正文“删除当前设备中已有的诊断日志，无法恢复。训练计划、记录和备份不受影响。下载目录中已导出的诊断包会保留。若记录仍开启，之后会继续生成新日志。”

按钮“取消”“清空日志”，默认焦点在取消，危险按钮使用danger/onDanger。成功后原范围归空，新产生的日志按当前开关记录；不要求新日志字节永远为零。提交中防重复及破坏操作的返回，失败保留真实结果。

L08说明日志包含必要技术状态和操作经过，排除名称、输入正文、重量及完整训练记录；即使脱敏仍可能体现使用时间和习惯，不称完全匿名。常规与详细模式均不自动上传。应用私有日志不进入应用手动完整备份，按平台能力排除系统备份；不扩大为对所有厂商迁移绝对保证。关闭、清空与公共导出文件是三个不同动作。

## 8. 视觉与无障碍

直接复用现行语义色和四种主题色，不引入新调色板、字体下载、图标库或装饰背景。浅色背景/表面为#F5F7F8/#FFFFFF；深色为#111518/#191E22。青色主操作浅色#087F6B配白字，深色#5DD9B6配#102A22；警告与失败使用现有warning/danger配对。图标用现有Material线框语义；画板内系统栏与外框仅示意。

页面水平内距24 dp；分区24/32，行间8/12/16；卡片16、主按钮14、弹窗20 dp圆角。正文16 sp，辅助14，标注12；页标题18/28，结果标题24。主按钮至少56 dp，其余目标至少48×48 dp，标签与触控高度都允许随字体增高。

适配规则：360/430 dp和1.0/1.3/1.6字号下正文自然换行，容量的数值和单位作为相邻单元重排；长文件名可在连字符等位置或必要字符间换行，不裁切或省略。窄屏预览中的键值改为上下排列。横屏/约768 dp平板复用AppTaskLayout的双区布局，正文限制可读宽度，短屏可滚动。固定区必须为正文预留全部高度与系统inset。

取消、错误和成功均有文字，不能只靠颜色；开关读出名称与开关状态。过程和结果使用适当live region，不抢走用户输入焦点。模态打开后焦点进入，关闭后回触发处；危险动作不默认聚焦。一般过渡沿用160–220 ms，面板约240 ms；减少动态效果时取消不必要位移。动画不得延迟写入、修改截止或阻止取消。

## 10. 草图检查及后续验收边界

静态检查覆盖三张流程画板、修订设置完整长图及入口局部；指定区域文字宽度检查无超限，主文字语义配色已做浅深对照。此前认可的 L01/L02 保持像素一致，02/03两组画板保持文件哈希一致。PNG使用Windows现有字体，SVG保留文字与矢量形状供后续编辑。记录见[设计资源检查](settings-revision-checks.json)和[文档接入检查](documentation-checks.json)。

后续实现必须验证：L01各分支真实状态、开关持久化失败、无操作日志导出、全部及局部采集失败、真实Download写入核验、空间不足、旧版本权限、导出取消与发布竞争、重复操作、启动数据库不可用、训练进行中、系统返回及上下文保留。

适配与辅助技术验收应覆盖中英文、浅深及四主题色、360/430 dp、最大字号、长文件名、横屏、平板、TalkBack和减少动态效果。当前Widget预览矩阵覆盖384组合，另有主要页面的大字号短屏检查及API36真实运行截图；这不代表全部状态、TalkBack或真机人工验收完成，详见实施验收。
