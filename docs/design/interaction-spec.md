# A 方案：交互、条件与异常规范

版本 `focus-a-2026-10-14`。这些规则说明现有能力在目标 UI 中如何表达，配合[页面清单](screens-and-states.md)及[验收标准](acceptance-checklist.md)使用；不是业务变更提案或开发任务。

## INT-01 数据范围与输入

计划默认配置与本次训练快照独立。修改或删除原计划不改变活动会话与历史；本次排序、组数和休息调整不回写原计划。历史显示最终快照顺序，不伪造为时间线。

普通计划名去除首尾空白后非空，最多 40 个可见字符，允许重复；动作名最多 60。重量可选且仅参考，按现有有限正数、小数解析规则；不新增备注、估算时长、逐组次数或重量。输入校验错误靠近字段，保存失败保留内容，成功才关闭。

组数为 1–100，步进 1；休息以秒保存，范围 0–3600，步进 30。保留现有 Picker 滑动吸附及有效档位轻反馈，显式加减是相同规则的替代操作。范围端点不可继续递增／递减；不在未改变有效值时重复触发档位反馈。

## INT-02 开始与恢复

计划详情先进入准备页，确认后才创建训练快照。空计划不能开始。一次只允许一场未结束训练；开始冲突显示原会话名称，提供继续原训练／留在当前页，不覆盖旧会话。

首页的继续卡片反映真实活动会话，即使来源计划已删除仍能恢复。完成、撤销、跳过、换序、本次配置与休息截止遵守既有持久化；应用后台／重启后以最新状态继续。加载中、读取失败和可重试状态不得冒充空数据。

## INT-03 会话操作可用条件

条件来自现有 `WorkoutSessionData`、`SessionExercise` 及仓储约束；UI 不能另建宽松条件绕过它们。提交中统一防止重复执行。

| 操作 | 出现／允许条件 | 反馈与范围 |
| --- | --- | --- |
| 完成本组 | 有待练组、当前不是休息或写入中 | 一次只完成当前身份对应的一组；瞬时连续点按不自动跨到下一组 |
| 结束休息、±30 秒 | 当前有休息截止且非写入中 | 只改变当前休息；结束休息不完成组 |
| 跳过剩余 N 组 | 会话进行中，当前动作至少一组真实完成，仍有待练组；训练中或组间休息 | 动作间休息不显示；先 D08 确认，N 是当前待练数 |
| 撤销上一组 | 至少有真实完成记录 | 按实际提交先后撤销，不按动作／组行顺序；保留所有跳过标记 |
| 撤销最近跳过 | 最新一批跳过仍可恢复 | D09 显示对象和数量；与普通撤销独立 |
| 更换下一动作／剩余换序 | 有待练组，零完成且零跳过的可移动动作数量大于一 | 移动候选仍受锁定位置约束；候选不足时不提供无效操作 |
| 编辑本次配置 | 原有未完成动作编辑规则允许，且不含跳过组 | 仅目标组数与两类休息；最小组数 max(1, 已完成数)；含跳过时解释先恢复 |
| 保存训练 | 至少一个真实完成组，且会话允许结束 | 可提前保存；没有待练组时不意味着完成率 100% |

可暂时禁用的操作应可理解地说明原因；永久不适用的操作不强行占据主操作位。当前对象或候选在弹窗期间变化时，按现有 token／身份校验拒绝过期提交并重新加载，不能把旧确认作用到新动作。

## INT-04 完成、跳过与两类撤销

1. 完成一组后仍有当前动作待练组：按组间配置休息；当前动作已无待练但全场还有待练：按刚完成动作的动作后配置休息；配置为零直接进入待练；全场无待练进入结束确认。
2. 确认跳过：保留目标与真实完成记录，剩余组记为跳过；取消当前组间休息并直接进入下个待练动作，不额外创建动作间休息；无待练则结束确认。取消 D08 保持原状态和截止。
3. 普通撤销：撤销最近真实完成组、取消关联休息并定位回该组；顺序和跳过事实不变。相同时间戳仍按提交顺序决定，不按显示顺序。
4. 恢复跳过：仅恢复最近一批，保留所有真实完成组，包括后来在其他动作完成的组；回到被恢复的动作。确认／取消使用明确动词。
5. 含跳过组动作先恢复跳过再允许本次编辑；不能通过减少组数抹除跳过事实。普通撤销降到零完成，也不自动清除跳过记录。

实际进度始终是 `真实完成组数 / 目标组数`。待练指既未完成也未跳过的组；全场待练为零只表示可结束。完成、跳过、未完成有文字和符号，历史按真实状态保留。

## INT-05 本次换序与编辑

只有零完成、零跳过且仍有待练组的动作可移动；其他动作位置锁定。手柄、锁定标签、上移／下移应反映同一候选集合，跨锁定槽位的含义沿用现有算法，不移动被锁定动作。

当前动作未开始时，快捷选择可替换当前；当前已有完成组时只调整之后的待练动作。UI 解释当前情形，不统称“直接跳到任意动作”。保存仅影响本次快照；取消不写入；重新从原计划开始使用默认顺序。

进入编辑的是**选中的会话动作身份**，不总是当前动作。允许字段仅组数、组间及动作后休息；名称和参考重量不在现有本次编辑范围。失败保留表单并允许重试，过期状态先重载。

排序、打开列表、选择、语言或主题切换都不暂停／重启当前休息。草稿写入与返回使用现有提交保护，不能在成功关闭动画期间再执行保存。

## INT-06 两类休息、提醒与权限

倒计时由持久化的绝对截止时间计算，显示 `mm:ss`；不是仅靠前台每秒递减。弹窗打开、切后台、换序和语言变化期间截止继续推进。减到零、主动结束休息、跳过、撤销或结束训练都不冒充自然到期。

自然到期可反馈一次：前台短音／视觉反馈，后台或锁屏本地通知；不自动完成训练组。系统静音、勿扰、通知渠道和当前能力必须被尊重，不强行绕过或承诺必达。

| 能力状态 | 呈现与入口 |
| --- | --- |
| 用户关闭提醒 | 明确关闭，计时与训练继续；不强求授权 |
| 通知允许且准时能力具备 | 明确可用，不承诺所有厂商或进程场景必达 |
| 通知拒绝／渠道禁用 | 后台不可用的明确说明、相应系统设置入口；前台反馈按既有能力工作 |
| 准时权限缺失 | 明确后台可能延迟、准时提醒设置入口；不误写成训练失败 |
| 调度失败 | 训练完成结果已保存的前提说明、重新同步入口 |
| 开关偏好写入失败 | 保留／恢复真实偏好并允许重试，不假装已切换 |

只在合适时机解释并请求原生权限，拒绝不阻断完成记录，不在每组重复申请。关闭再开启只安排有效未来休息，不重置截止或补播旧事件；时间、顺序、语言变化后通知内容随有效修订更新，取消使旧提醒失效。

点击通知验证所属训练，并返回该会话的最新状态。目标已结束、删除、过期或不合法时提示不可用，不打开另一场训练，也不堆叠重复页面。系统授权、设置及通知真实外观由 Android 决定。

## INT-07 结束、返回和取消

训练页标题返回、退出入口或系统返回都展示会话处理选项，不能静默丢弃。D05 有完成组时提供保存／继续／放弃；选择放弃再进入 D06。零完成不提供保存，可继续或直接放弃，不重复无意义确认。

保存包含实际完成、跳过及未完成的快照；统计只计真实完成组。失败保留当前会话并提供可理解的重试，不能提前跳到历史或把失败当成功。成功结束取消关联提醒，并刷新首页／历史。

菜单返回关闭菜单；动作列表／选择／排序关闭返回原训练状态；取消排序丢弃草稿。表单取消不保存；取消删除、跳过、恢复不会写数据。非提交中，外侧关闭和 Android 返回按现有取消语义处理；提交中阻止重复提交和可能破坏事务的返回，不影响绝对计时。

命名表单检查通过并保存成功才关闭；错误保留内容和焦点。其他多步确认依各自真实事务流程显示“提交中”，不强制将所有操作都改为同一关闭时机。需要放弃已有训练记录时维持二次确认。

## INT-08 导出与导入

### 导出

进入默认全选，按需取消、单选或再次全选，所选数量即时更新。无选择时两种输出不可提交；保存／复制中防重复。导出按现有列表顺序获取完整一致快照，提交前所选计划已消失则告知重新选择，不能静默漏项成功。

复制成功显示数量；文件成功后显示实际文件名及公共下载位置，重名不覆盖旧文件。拒绝权限、不可写或失败准确说明并保留选择。备份只含计划及动作配置，不含历史、活动会话、偏好。不能新增自定义导出目录或云盘流程。

### 导入

手动输入／粘贴、主动点击粘贴、系统文件选择共用既有校验。进入页面不自动读剪贴板；取消选择正常返回不写数据、不误报失败。内容为空、损坏、版本不支持、超限、字段无效使用本地化业务错误，不展示内部堆栈。

预览完整配置、名称、计划数量，允许修改待导入名称；同名按现有语言后缀规则创建副本。副本名展示后再确认；确认时发现新占名需更新预览重新确认，本次不写入，不能暗中改名保存。保存后名称成为用户内容，不随语言切换翻译。

整批新增全部成功或回滚，不覆盖已有计划或改变活动休息。失败保留有效预览可重试；取消／重新选择丢弃相应草稿。输入范围、UTF-8 大小、传输格式、未知字段兼容等仍由现有格式与规格决定。

## INT-09 历史、删除与统计

列表按既有月份与日期规则加载；自然周／月训练次数与所选月时长、完成组数是不同口径。历史月份为空时仅相应月汇总归零；全部历史为空时次数、时长、组数归零，最近训练暂无。跳过和未完成不计完成组数。

记录详情展示快照名称、日期、时间范围、时长、动作顺序及三类组结果。删除入口在该详情更多菜单，确认包含目标名称、日期、不可恢复与统计同步说明；与删除计划／动作的范围说明不同。

取消保留详情；确认只删除目标已保存记录，原计划、其他历史和活动训练保持。重复点击只提交一次。删除失败保留可重试状态；目标已不存在不伪报本次成功。删除成功但刷新失败提示“已删除，刷新失败”，只重试加载；所选月份保留，过期请求不能恢复旧记录或统计。

## INT-10 主题、语言与辅助操作

主题提供系统／浅色／深色，语言按 English、中文排列；选择持久化失败反映真实状态。语言初始化、地区变体、回退沿用 `app-localization`，不新增跟随系统语言选项。

切换保留 Navigator 上下文、活动页面、输入、选择、动作身份、已记录组及休息截止；已打开的提示／弹窗按当前语言更新。用户名称、已保存副本后缀、历史内容不改写。数量与日期格式按现有层，示例固定数值不可写入实现。

焦点顺序与视觉顺序一致；标题、当前组、倒计时、状态与操作有可理解的读屏语义；提示变化不抢走用户输入焦点。拖动有非拖动替代，装饰图标不重复朗读；放大字体优先换行和滚动。具体阈值见主规范与验收清单。
