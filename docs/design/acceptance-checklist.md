## VIS：视觉与组件（Flutter 验收）

| ID | 检查 | 观察与通过条件 |
| --- | --- | --- |
| VIS-01 | 两套语义主题 | 所有页面及系统内应用组件、菜单、弹窗、输入、导航、反馈使用主规范语义，不混用旧色和独立生成色板 |
| VIS-02 | 对比与状态 | 文字至少 4.5:1，大字至少 3:1；必要边界、图标和焦点至少 3:1；浅底主色文字单独核对；状态不只靠颜色 |
| VIS-03 | 排版与参考重量 | 标题／正文／辅助层级一致，数字稳定；当前组与已完成数清楚；重量说明为参考；不出现未实现的估算时长或备注 |
| VIS-04 | 按钮与命中 | 主按钮至少 56 dp，其余操作至少 48×48 dp；含图标、更换、排序替代和开关命中区域；长按钮增高、不裁字 |
| VIS-05 | 组件状态 | 默认、按压、焦点、禁用、提交中、失败恢复可区分；无误导性的可点空操作，按压不改变布局 |
| VIS-06 | 数值控件 | 同一有效值支持显式加减与既有滑动 Picker；组数 1、休息 30 秒步进；有效档位吸附和触觉，无变化不重复反馈 |

## ADAPT：本地化、屏幕与可访问性（实施验证）

| ID | 核验矩阵 | 合格标准 |
| --- | --- | --- |
| ADAPT-01 | 360 / 430 dp × Light / Dark × 中文 / English | 主画面、所有弹窗、菜单、滚动末尾与主操作无溢出或遮挡；使用约束而非固定 390×844 |
| ADAPT-02 | 字体 1.0 / 1.3 / 1.6，长计划／动作名、长译文 | 标题与按钮换行、正文可读；超长名称可完整查看；最大组数用摘要，不挤成细小标记 |
| ADAPT-03 | 键盘可见、小屏短屏、横屏、约 768 dp 平板 | 当前输入、错误和确认可达；主动作区预留空间，系统区域不被拦截 |
| ADAPT-04 | 系统／浅／深主题与语言即时切换、重启 | 偏好按实际成功持久化；失败反映原值；页面、草稿、选择、完成数与绝对休息截止保持 |
| ADAPT-05 | 中英文日期、月份、时长、复数与小数输入 | 使用现有资源和格式化层；用户名称及保存后副本名不翻译；倒计时仍 mm:ss |
| ADAPT-06 | TalkBack、键盘／辅助输入与非拖动替代 | 控件名称和状态可理解，焦点顺序正确；弹窗焦点可恢复；计时不逐秒抢播；所有必要操作不依赖拖动 |
| ADAPT-07 | 减少动态效果、轻反馈与按压 | 关闭不必要位移；动画和触觉不阻塞写入；无布局抖动或连续闪烁 |

## 证据与限制

DOC 类资料整理及浏览器设计稿检查的历史结果见[验证说明](verification/README.md)；本次 Flutter 实施结果单列于[实施报告](../qa/focus-a-redesign-acceptance.md)。`docs/qa/` 中既有 Android 证据证明对应批次旧界面的功能验收，不能作为 A 方案已落地的验收报告。

未来获批实施时优先使用既有有效回归及必要的 UI／平台验证，不编写只镜像样式常量的测试。记录设备、版本、主题、语言、字号、操作和结果；区分自动化、模拟器、真机及尚未验证条件。规范更新不自动授权执行此表中的开发工作。
