# SetTrace · A–E Logo 草图

2026-10-15，第一轮概念比较，每个方向一稿。

- 打开 index.html 比较、切换配色及放大查看；无需网络或安装依赖。
- comparison.png / comparison.svg 是五方案静态对比图。
- marks/ 下是五套透明 SVG / PNG 标记。SVG 使用 currentColor，可改变颜色。
- App 圆角底板仅用于桌面图标效果示意；尚未制作平台图标包或接入 App。
- SetTrace 字标使用系统字体进行组合示意，尚未进行专属字体设计。
- 依据 docs/design 当前 Focus UI 的配色、圆角、专注与秩序感独立创作，未读取现有图标素材。

| 方向 | 名称 | 构想 |
| --- | --- | --- |
| A | 组间节奏 | 三道连续短节与一道断开的短节，共同表达训练与休息的交替。相同长度保持稳定节奏，轻微倾斜提供行动感。 |
| B | 行进的 S | 一笔等粗轨迹经过两次圆角回折，形成 SetTrace 的 S。保留宽阔负形与完整路径，表达训练持续进行、每组都留下记录。 |
| C | 当前一格 | 四个圆角模块组成紧凑方阵，三格实心、一格镂空。把训练页中的组状态提炼成整体符号，让当前关注点由形体而非颜色区分。 |
| D | 训练刻度 | T 形主轴配两道短刻度，表达逐组计数与清楚定位。圆角端点承接界面语言，主轴和横向刻度形成可靠的工具感。 |
| E | 留痕印记 | 以实心圆形作为印记，将一笔带回折的轨迹从内部挖空。通过实与虚的关系表达记录被留下，突出紧凑、稳定、易识别的轮廓。 |
