# SetTrace A · 专注工具：UI 设计规范与 Flutter 映射

版本 `focus-a-2026-10-14`。本文件替代原路径的旧设计规范；原文与三张旧高保真图已[归档](archive/legacy-2026-10-14/README.md)。这是当前目标设计规范；Flutter 实施及验证结果见[实施报告](../qa/focus-a-redesign-acceptance.md)，已按用户要求归档，未验证条件仍按报告记录。阅读范围、资料优先级及授权边界见[设计入口](README.md)。

## 1. 产品与范围

SetTrace（训练本）是轻量、离线优先的训练记录工具。训练中最频繁的操作是“完成本组”；界面减少记忆、查找和精确点按负担。

本设计覆盖当前全部功能：计划与动作管理、默认顺序、训练准备、单会话恢复、逐组完成、本次配置与待练换序、两类休息、提醒与权限、跳过剩余组和两类撤销、结束保存与放弃、历史统计和删除、计划导入导出、主题与语言。

不增加账号、云同步、课程、AI、逐组重量／次数、执行计时、训练备注或预计训练时长；重量保持计划中的可选参考值。保持数据库、训练快照、统计、导入格式和业务校验的既有含义。

## 2. 信息与导航

### 2.1 层级

- 一级：计划、记录、设置；底部导航顺序固定，图标配文字。
- 计划链路：列表 → 详情 → 动作编辑或准备 → 训练。
- 会话工具：查看全部动作 → 本次编辑／调整剩余顺序；选择下一动作是待练顺序的快捷入口。
- 历史链路：月份列表 → 详情 → 更多菜单 → 删除确认。
- 导入导出：计划首页更多菜单；首页“新建”继续独立可见，空首页可导入。
- 深层页面使用返回；训练、准备和编辑页不因放入底部导航而改变现有导航栈。返回行为见交互规范。

### 2.2 训练布局

从上至下为计划上下文、动作位置与“查看动作”、动作名称及参考重量、当前组或倒计时、当前可用的修正工具、下一动作与更换入口、实际完成进度。

底部主操作区与内容滚动区独立，给正文预留完整空间，不能覆盖末行内容。主按钮按状态显示“完成本组”“结束休息”或“保存本次训练”；位置稳定。大字号、横屏与短屏允许内容滚动和控件重排，不能靠缩小正文字号保住首屏。

“跳过剩余 N 组”与“撤销最近跳过”为有标签的独立次要操作；“撤销上一组”与“结束训练”在底部次要区。动作出现条件见 `interaction-spec.md`，不可为视觉整齐而展示无效入口或合并含义。

## 3. 语义颜色

所有颜色通过主题语义引用；页面、菜单、弹窗、输入、Snackbar、导航、进度和原生 Material 组件映射同一体系。不能只修改卡片颜色而让生成的 Material 色板继续决定其余组件。

| 语义 Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| background | `#F5F7F8` | `#111518` | 页面底色 |
| surface | `#FFFFFF` | `#191E22` | 卡片、输入、菜单、弹窗 |
| divider | `#DBE3E5` | `#354047` | 装饰分隔与进度底色，不单独承担必要边界 |
| controlBorder | `#71858C` | `#82969D` | 输入框、线框按钮等必要边界 |
| textPrimary | `#19262C` | `#F0F5F6` | 标题与正文 |
| textSecondary | `#586970` | `#ABB9BF` | 辅助正文 |
| accent | `#087F6B` | `#5DD9B6` | 主按钮、关键交互、当前组 |
| onAccent | `#FFFFFF` | `#102A22` | 主色实底上的内容 |
| accentSoft | `#E2F2ED` | `#203B35` | 低强调选中底色 |
| onAccentSoft | `#076D5C` | `#5DD9B6` | 浅主色底上的文字；Light 不能直接复用 accent |
| danger | `#B13C35` | `#FFB4AB` | 删除、放弃、错误 |
| dangerSoft | `#FFF0EE` | `#422923` | 错误浅底 |
| onDanger | `#FFFFFF` | `#111518` | 危险实底按钮内容 |
| warning | `#855208` | `#F0CA83` | 已跳过、能力受限 |
| warningSoft | `#FFF1D8` | `#3E3322` | 已跳过或受限状态浅底 |
| disabledSurface | `#E5E9EB` | `#2C353B` | 禁用填充 |
| disabledText | `#63747B` | `#A3B0B6` | 禁用文字，配合真实禁用语义 |

要求：普通文字对比度至少 4.5:1，大字至少 3:1；必要控件边界、独立信息图标、焦点至少 3:1。禁用、装饰分隔按其语义验收，不能用低对比装饰线充当唯一输入边界。Light accent / 白色约 4.93:1；accent / accentSoft 约 4.26:1，故浅底正文另用 onAccentSoft。两种主题独立核验，不能只做颜色反转。

完成、当前、跳过、待练、错误必须同时有文字、符号或位置区分，不能仅依赖颜色。完成用勾选，跳过用减号与“已跳过”，当前组有边界及“当前”语义。

## 4. 排版、数字与图标

| 角色 | 基准字号 sp | 字重 | 行高建议 |
| --- | --- | --- | --- |
| 页面大标题 | 28 | 600–700 | 1.3–1.4 |
| 分区／弹窗标题 | 22–24 | 600–700 | 1.4 |
| 导航栏标题 | 18 | 600 | 1.4 |
| 正文／按钮 | 16 | 400／600 | 1.45–1.55 |
| 辅助正文 | 14 | 400 | 1.5–1.6 |
| 简短标注 | 12 | 400–600 | 1.5 |
| 当前待练组 | 80 | 600–700 | 1.1 |
| 休息倒计时 | 70 | 600–700 | 1.1 |

中文目标字体为 Noto Sans SC，数字与拉丁字可用 Roboto／平台可用字体；不为字体额外引入网络依赖。HTML 使用 Segoe UI / Microsoft YaHei UI 等系统回退，不能将其像素差异当作 Flutter 字体已确认或要求新增字体包。采用中文完整字形回退并验证两语；数字使用等宽数字特性，倒计时保持 `mm:ss`。

`03` 表示“当前待练第 3 组”，不能冒充已完成 3 组。旁边必须说明“共 4 组／已完成 2 组”；读屏为完整语义。参考重量前始终有“参考”，空重量可不占位。

图标统一线性风格，通常 20–24 dp、约 1.7–2 dp 笔画。Flutter 优先使用已有 Material 矢量图标，匹配语义；不用 emoji 作为导航或状态结构。独立图标按钮必须有本地化的可访问名称。

## 5. 尺寸与适配

- 间距采用 4 / 8 / 12 / 16 / 20 / 24 / 32 dp；页面水平内距通常 22–24 dp，紧凑屏可按可用宽度调整。
- 卡片圆角 16 dp，主按钮 14 dp，输入 10–12 dp，弹窗 20 dp，底部面板上角 24 dp。系统窗口与预览手机外框不属于应用组件。
- 主按钮最小高度 56 dp，其余可操作区域至少 48×48 dp；相邻独立目标尽量保留 8 dp 间距。视觉图标可以更小，命中区域必须充足。
- 触控高度是最小值；英文、长译文和大字号时换行增高，不能固定单行裁切。长计划／动作名在详情和确认中完整可读，列表如摘要截断，进入详情可读全称。
- 以 360 和 430 dp 竖屏为主要布局核验，390×844 是设计展示尺寸；不可硬编码为运行尺寸。160% 字号、长文本和键盘状态必须核验。
- 横屏／低高度：当前任务与主操作可并排，次要工具滚动可达。平板约 768 dp 可将动作上下文与当前任务分栏，限制正文宽度；使用实际约束而非型号判断。
- 超过 8 组，采用完成／跳过／待练数量摘要及当前组文本，避免排列最多 100 个细小标记；总目标与实际完成数不变。
- 表单适配键盘的实际遮挡；当前字段、错误和确认操作均可到达。固定底栏、系统状态栏、手势区域的安全间距由设备 inset 决定。

## 6. 组件规范

### CMP-01 按钮

每个任务区只有一个主操作；主按钮 accent + onAccent。次按钮 accentSoft + onAccentSoft，线框按钮 surface + controlBorder。危险按钮 danger + onDanger；文案用“删除记录”“确认放弃”等具体动词。取消与保留不使用危险色。

包含默认、按压、键盘／读屏焦点、禁用、提交中和失败恢复状态；按压不改变布局尺寸。提交中显示进度并防重复提交；禁用必须同时有不可执行语义及相关原因。不得把未来模拟成功、点击后即成功或数据库失败吞掉当作产品行为。

### CMP-02 卡片与动作行

卡片限定用于需要分组的内容，减少层层套卡；普通动作使用有序行与分隔线。行显示名称、目标组数和休息摘要；当前位置、完成和锁定状态有标签。导航行有明确点击区域；仅装饰性的图标不重复进入读屏树。

### CMP-03 数值 Picker 与输入

组数 1–100，步进 1；两类休息 0–3600 秒，步进 30 秒。**保留当前规格的滑动 Picker、有效档位吸附与跨档轻反馈，增加显式减／加作为并行操作。** 不改变存储单位，不为按钮改数据库。最小／最大值时对应操作不可继续；本次编辑组数还受已完成数约束。

名称输入有常驻标签、长度约束与就地错误，普通计划名称允许重复。计划名称最多 40、动作名称最多 60 个可见字符；去除首尾空白后不得为空。重量可选，只接受现有有限正数规则，支持当前语言允许的小数输入；不得补成每组重量或次数记录。

### CMP-04 确认弹窗与底部面板

简单命名和后果确认用弹窗；较长动作列表、选择和换序用可滚动面板或等价完整页面。弹窗显示对象、影响和动作，不只写“确定”。长内容滚动，按钮不被键盘或安全区遮住。默认聚焦当前任务，关闭后返回触发位置；危险确认不默认聚焦破坏性动作。

新建／改名只有成功才关闭；字段错误保留草稿。删除明确对象、不可恢复与保留范围；有完成记录时放弃二次确认。不同删除对象不能共用模糊“会删除全部数据”文案。

### CMP-05 进度与反馈

进度分子仅实际完成组，分母为目标组；跳过不增加分子。全场没有待练组时可结束，但不一定 100%。自然到期反馈、正常成功、取消、写入失败、刷新失败和过期状态分别表达；不能只有颜色或瞬间消失的提示。

字段错误就地显示，页面操作失败使用持久提示与重试；短成功反馈使用不遮挡主操作的 Snackbar／页内反馈。删除成功但刷新失败只重试加载。提醒调度失败不能显示训练未保存。

## 7. 本地化、可访问性与动效

- 所有应用文案进入既有 ARB；计划／动作名及已保存导入副本名是用户内容，切换语言不翻译或改写。
- 设置语言顺序 English、中文；首次系统匹配、偏好持久化和失败回滚沿用既有规则。日期、月份、数量、时长和小数用当前格式化层；倒计时固定 `mm:ss`，单位与数值不能混淆。
- 主题／语言切换保留页面、草稿、选中内容、训练进度和休息截止时间；不是仅换两张静态示意图。
- 明确读屏顺序、选中／禁用／展开状态和表单错误；装饰图标隐藏。倒计时不逐秒打断播报；组完成、到期和关键错误按实际变化播报。
- 拖动保留手柄，并提供上移／下移等不依赖拖动的替代方式。两种方式都遵守相同锁定规则，不引入新的排序能力。
- 按压反馈应在约 100 ms 内出现，内容切换 160–220 ms，面板约 240 ms；支持减少动态效果，关闭不必要位移。可随平台调整，不得因动画或触觉延迟持久化。
- Android 返回、系统手势、权限和设置使用平台约定；系统授权／通知外观由系统决定，不按 HTML 仿画覆盖原生能力。

## 9. 关于与首次说明组件扩展

`add-app-about-and-first-run-notice` 的 C05/D15/D16 沿用本规范的语义色、排版、组件与适配，无独立配色。关于位于设置已有分区之后，区间距 24 dp、标题与卡片 12 dp、单层 AppCard 圆角 16 dp。正式三线标志 40 dp，取 `settrace-brand-final` 母版，保持比例／单色／净空，深浅主题用对应资源；不更换启动器图标。

关于直接显示 SetTrace、简介、安装版本和构建号，链接为有标签的普通行。弹窗使用 CMP-04 的 20 dp 圆角、22–24 sp 标题、16 sp 正文，长内容滚动，主操作至少 56 dp、其他命中至少 48 dp；大字号换行增高而不缩字。默认、提交、失败重试及仅本次继续均使用 CMP-01/05。详细数据范围与返回见 INT-11。

计划入口统一为已有 Material `list_alt_outlined`，继续使用 22 dp、既有选中底色和当前语言标签，与记录／设置视觉重量一致。先前放大预览仅用于选型，不是布局尺寸。实施验证见独立 QA 报告。

## 10. 主题色预设增量

`add-theme-color-presets` 将青色扩展为青色、蓝色、紫色、石墨四个独立预设；每个预设与系统／浅色／深色模式自由组合。正式 ID 为 teal、blue、violet、graphite，持久化 `theme_color`，旧版或无效偏好回退青色。

| ID / 模式 | accent | accentPressed | accentSoft | onAccent | onAccentSoft |
| --- | --- | --- | --- | --- | --- |
| teal / light | #087F6B | #076D5C | #E2F2ED | #FFFFFF | #076D5C |
| teal / dark | #5DD9B6 | #41C6A3 | #203B35 | #102A22 | #5DD9B6 |
| blue / light | #245FC7 | #1E50AA | #EAF0FC | #FFFFFF | #1E50AA |
| blue / dark | #9BBDFF | #82AAEF | #1D3152 | #10264D | #B6CEFF |
| violet / light | #7046B8 | #603AA4 | #F1EBFA | #FFFFFF | #603AA4 |
| violet / dark | #CCB2FF | #B89AEF | #362746 | #2B1648 | #D8C5FF |
| graphite / light | #303A43 | #222B33 | #E8ECEF | #FFFFFF | #303A43 |
| graphite / dark | #D6DDE3 | #B9C4CD | #30383F | #1C252D | #D6DDE3 |

只覆盖五种强调角色。背景、表面、边界、正文、危险、警告、禁用和正式品牌资产保持。Material 主色及容器、导航、输入焦点、进度、反馈操作均由预设驱动；Snackbar 的逆表面操作前景使用另一明暗配色的 onAccentSoft，保证至少 4.5:1。主按钮 pressed／focus 使用 accentPressed，避免浅色状态层使文字低于 4.5:1。

C01/C02/C04 中在外观与语言之间增加单层 AppCard：圆角／内距 16 dp，36 dp 色圆，2 dp 外圈与 3 dp 间隙，不显示颜色名称，选中勾号＋外圈；整项至少 48×48 dp，相邻至少 8 dp。四项默认保持一行，不受语言和字号影响；仅容器不足 232 dp 时两列重排，保留完整触控区域。颜色名称及默认属性仅提供给辅助技术。状态说明间隔 12 dp、14 sp；保存中和失败就地表达，失败提供至少 48 dp 的重试。

颜色即时预览并异步保存，常规过渡 200 ms，可被新选择打断；减少动态效果时直接更新。单选状态与读屏语义不依赖颜色；保存和动画不阻塞返回或改变训练时间。实施及测试证据见 [主题色验收](../qa/theme-color-presets-acceptance.md)，不以色值核算代替设备验证。

- D17：前台居中弹窗，背景用约 50% 黑色遮罩压暗；浅深模式分别核对对比度。弹窗使用 surface、20 dp 圆角、24 dp 内距，标题 24 sp、正文 16 sp、辅助文字 14 sp；不闪烁、不循环动画。
- 正文依次为“休息结束”“可以开始下一组了”、当前待练动作、“第 N / M 组”；开启重复时补充“未确认时，每 X 秒提醒”。唯一主按钮“知道了，停止提醒”至少高 56 dp。关闭后保留原训练页固定底部“完成本组”，确认不记录训练进度。
- C01/C02/C04：现有提醒单层卡片内依次为总开关、提示音及独立试听、振动、重复提醒、提醒间隔；设置分区顺序不变。默认三音提示（约 1.5–2 秒）、两次短振动、重复开启、间隔 10 秒；音色与响度后续需真机试听确认。
- D18：间隔单选面板提供 10／15／30／60 秒；D19：提示音单选面板提供三音提示、双段电子提示、短音＋语音，各项可独立试听。面板使用 24 dp 上圆角，选择后“保存”，返回／下滑关闭不保存。
- 继续执行 VIS-01–05、ADAPT-01–07：长文案和大字号换行增高，短屏内容可滚动、确认始终可达；读屏不逐秒打断，关闭后焦点恢复，提醒确认不穿透为“完成本组”。系统通知外观由 Android 决定。
