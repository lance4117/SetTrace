# 备份与恢复 UI 设计

> 当前参考整理：2026-10-31。沿用 focus-a 及已实施增量；当前应用基线和验证结论以 manifest.json、verification/results.json 为准。文中链接到的旧 HTML、草图、旧日期报告仅为来源追溯，不是当前构建截图。发现要求与实现差异时登记，不修改业务规则。


状态：已按获批提案实施到 Flutter，验收进行中；实际通过范围见[独立验收](<../../../../qa/backup-restore-acceptance.md>)。初稿：2026-10-16，实施更新：2026-10-17。基线：`focus-a-2026-10-14` 及四主题色、关于、休息提醒增量。

配套：[可点击设计稿](<../../../archive/2026-10-31-design-history/docs/design/backup/index.html>)、[目录与证据](<backup.md>)。

## 1. 范围与设计默认值

用户已确认：首版用于防丢失与换机，允许整份替换已有数据；先保存并校验恢复前副本，失败保留现有数据；恢复后可以撤回，撤回前也保留当下状态。自动同步留到以后。

覆盖设置入口、数据概况、创建备份、文件选择、兼容性反馈、恢复预览、确认、处理与结果、副本列表、撤回、导出／删除副本、活动训练及中断。

现有 X01–X04 继续只分享计划，沿用原格式和新增副本语义。本功能采用独立备份格式，历史保留当时快照，完成／跳过／未完成、日期和时长口径保持。

下列默认规则已纳入获批变更 `add-full-data-backup-restore`；三个主规格已同步并归档，43/45项完成，剩余设备验收独立记录：

| 项目 | 建议规则 |
| --- | --- |
| 完整范围 | 全部计划、动作配置、已保存训练完整快照、可迁移设置；无按月份或单条选择 |
| 活动训练 | 创建／恢复前先引导处理；不漏掉进度，不自动结束、保存或丢弃 |
| 设置 | 备份包含外观、语言和提醒偏好；恢复默认勾选，可取消；不迁移权限、旧通知、首次说明已阅 |
| 外部文件 | 公共 Downloads，新文件名不覆盖已有文件；不把私有目录称为外部备份 |
| 保护副本 | 应用内持久保存，冷启动仍可读；卸载会删除，可另行导出 |
| 保留策略 | 不静默过期或覆盖；用户逐份确认删除；空间不足就停止新的恢复 |
| 撤回 | 整份回到指定旧状态，先保护现在的数据；不自动合并 |
| 提醒 | 页面内显示上次导出和此后有变化；不新增后台自动备份或催促弹窗 |

文件字段、64 MiB 上限、版本兼容及存储协调见[格式文档](<../../../../user-backup-format.md>)和[获批技术设计](<../../../../../openspec/changes/archive/2026-10-17-add-full-data-backup-restore/design.md>)。本稿描述 UI，数据库 v6 迁移及其证据由该变更管理。

## 2. 导航与视觉

设置保留外观 → 主题色 → 语言 → 提醒；在提醒之后、关于之前增加“数据”分区与“备份与恢复”导航行。入口不放左侧装饰图标，文字与其他设置项对齐，保留右侧进入箭头。B00 示意滚动到此处。深层页面使用返回，不重复显示一级底部导航。

复用 CMP-01–05：页面水平内距 24 dp；间距 12／16／24／32；卡片圆角 16、按钮 14、弹窗 20；主动作最小 56 dp，其他操作至少 48 dp。正文 16 sp、辅助 14、标注 12、页标题 18／28、结果标题 24，允许内容换行增高。

浅色 background／surface／正文／辅助为 `#F5F7F8`／`#FFFFFF`／`#19262C`／`#586970`；深色为 `#111518`／`#191E22`／`#F0F5F6`／`#ABB9BF`。青色及蓝／紫／石墨直接沿用主规范 §10。

成功与信息使用 accentSoft/onAccentSoft，替换说明用 warningSoft/warning，最终替换和删除用 danger/onDanger。普通创建和继续用主色；正常恢复入口不预先涂红。图标保持现有 Material 线框语义，HTML 用一致笔画 SVG 表达，不新增图标包或网络字体。

“当前设备 → 恢复后”对比数量，不把数量差表述为精确新增／丢失数量。文件名可换行，用户名称不翻译。界面不展示 schemaVersion、SQLite、事务、UUID 或错误码；应用版本仅在展开详情出现，兼容性依据文件协议判断。

## 4. 交互规则

### BK-01 创建

B01 → B02 显示确认时的完整范围。活动训练先 B15；真实提交时再次校验。不得漏掉活动会话再称完整成功；不改已有后台／重启恢复。零完成训练仍按既有继续／放弃规则处理。

提交后立即反馈并防重复，B03 只表达真实阶段。只有完整文件写入并核对后更新上次成功导出；失败清理本次未完成文件，保留已有备份。重名生成新文件名。

B04 持久显示文件名、公共位置、时间与数量；不只给短 Toast，不承诺自动同步。导出某个恢复前副本使用该副本内容，不能更新“当前数据上次导出”。

### BK-02 选择与兼容性

系统文件选择取消回 B05，清理旧候选和预览，不报成功或失败。真实读取失败 E14；耗时读取提供状态，写入前可以取消。

按内容识别文件，整份校验版本、结构、引用与状态后进 B06。错误 E01/E02/E03。完整备份上限为 64 MiB，与计划文件的 2 MiB 上限独立；超限无损停止，不要求删除历史。

旧备份在替换前完成转换和校验；新版不支持则拒绝整份。没有“尽量恢复能看懂的字段”选项，不要求用户先装中间版本。应用版本是来源信息，格式版本决定兼容性。

### BK-03 预览与确认

当前列为新鲜读取，目标列为已验证备份；预览后数据或文件变化使确认失效，E08 → B06 重新确认。数量差不等于精确的数据差异清单。

历史使用原快照、真实组状态、原训练日期和已保存时长；删除原计划后仍可恢复其历史；统计由恢复的数据计算。

设置默认勾选，可取消保留当前值；取消确认保留选择。确认前保持当前语言与主题，成功后按实际设置结果应用。

继续只打开 B07。一次后果明确的确认显示目标时间／数量、整份替换和保护承诺；不输入口令，不重复勾选。取消默认焦点，系统返回关闭确认、回到预览和触发焦点。

### BK-04 保护、恢复与结果

确认后再次检查预览与活动训练，先创建并核验完整可读的保护副本，成功才 B08a。失败 E06，没有跳过保护或强制覆盖。

核心替换期间暂时禁用返回和重复提交，禁止其他写入破坏已确认状态。原生通知、D17、通知导航通过共享写入协调与数据集身份检查，避免旧事件回放或导航到被替换的对象；UI 禁用不能代替数据一致性。

计划和历史全部成功／全部回滚。SQLite 与 SharedPreferences 的设置不能假设由一个事务覆盖，因此 E09 单独报告并重试设置；E10 只重新加载已提交结果。回滚未核实不能报告原数据完整。

成功后刷新计划、历史与统计，处理失效页面／缓存，设备权限重新读取，不补播旧提醒。B09 查看记录接 H01；撤回在 B09、B01、B10 都可找，不依赖短提示条。

### BK-05 副本与撤回

保护副本必须冷启动后仍可发现、校验和恢复，不放在会自动清理的临时目录。撤回指向具体操作的副本，不因查看其他副本而改变。

撤回 B11/B12 显示当前与目标，之后新增的数据也先另存；B13 校验保护成功再 B13a 替换，成功 B14。保护失败 E06 返回撤回预览；替换失败且回滚确认 E13。

旧副本可经 B19 → B06/B07 完整恢复。删除 B20 仅影响指定副本和对应撤回能力，不删当前记录；失败 E12。无自动过期或未经确认清理。

固定说明：“副本保存在应用内，卸载会删除。需要长期保留时，请将副本导出为文件。”不要把公开备份与应用内副本统称“数据已安全备份”。

### BK-06 中断

重新启动先 B16 检查持久化操作结果：旧数据完整 B17；新数据提交 B18；撤回已提交 B14；核心成功设置未完成 E09；仍无法判定则保留检查错误及重试，不能显示假空页或猜测成功。

界面没显示成功不等于事务没提交，不得重放恢复。禁用返回不能阻止系统杀进程；恢复日志已有自动化阶段故障验证，完整的设备杀进程验收仍待执行，见独立验收的 10.3 项。

### BK-07 返回与可访问性

返回退一级；文件取消回说明；确认取消回预览并恢复焦点；处理中防破坏提交，完成即恢复操作。成功后刷新失败仅重读。

主题、语言、字号变化保持页面、候选、勾选、数据与操作身份，不重触发恢复。正文可滚动，底部主动作独立且不覆盖正文末行；大字号和横屏弹窗可滚动，按钮始终可达。

普通文字至少 4.5:1，必要图标和边界至少 3:1。控件有名称、状态和至少 48 dp 目标；播报阶段变化而非每帧；焦点约束在弹窗，关闭恢复触发点；减少动画时保留静态进行中状态。
