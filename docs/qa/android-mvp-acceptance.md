# SetTrace Android MVP 验收记录

日期：2026-09-25。设备：Android 16 模拟器，1080×2400；分别以 480 dpi（360 dp）和 402 dpi（约 430 dp）查看，系统字体缩放 1.3 倍。视觉参考为 `docs/design/` 内的 High-Fi Light、High-Fi Dark 和 Design Tokens 图片。

## 核心流程

- 创建多个计划，改名、删除前确认；添加和删除动作、拖动排序后重开页面，名称与顺序保持。空计划不能开始训练。
- 从计划详情进入准备页，开始训练，完成一组后出现休息。后台切换、强制结束进程并重开后，已完成组和会话游标仍在；休息按绝对截止时间恢复。
- 训练中可查看完整动作列表并修改本次后续动作的组数与休息；本次把 Row 从 4 组、2.0 分钟改为 5 组、2.5 分钟后，训练页显示新值，原计划仍为 4 组。
- Android 返回键与页面退出均显示结束确认。零组会话确认丢弃不进入历史；完成组可部分保存，同日多场分别出现在记录页，详情使用开始训练时的动作快照。计划改名、动作删除和计划删除后，旧记录仍可查看。
- 关闭 Wi-Fi 和移动数据时，创建计划、训练、恢复、保存、查看历史以及重启后读取数据均成功；核心流程未出现登录或联网入口。

## 视觉与适配

- 语义色值与 Token 图一致；跟随系统模式下切换 Android 浅色/深色，两套主题沿用同一页面层级，卡片、文字、主按钮和底部导航对比清晰。深色选择重启后仍保留。
- 对照两张高保真图检查了计划、动作编辑、准备、训练、休息、记录页面。训练页突出当前动作、组数、进度与主按钮；当前卡片使用强调色边框，下一动作使用浅强调色背景。Picker 保持居中吸附与选中态；状态栏、底部手势区域未遮挡内容。
- 360 dp 与 430 dp 竖屏、1.3 倍字体下，训练主按钮可直接触达，下一动作卡和记录统计没有裁切。360 dp 下休息页两侧的“±30 秒”换为两行，按钮仍完整可点。完整动作列表和本次编辑页可显示并滚动。
- 设计图中的“预计训练时长”缺少计算规则，按提案未展示。按产品需求补充了完整动作列表、明确结束训练、本周统计和记录详情。
