# Design

## Context

动机见 [proposal.md](proposal.md)。已确认的设计来源为 [history-summary-2026-10-22](../../../../docs/design/history-summary/README.md)，在 `focus-a-2026-10-14` 主规范 §13 下补充 H01/H03/H05；该设计仍标记为 Flutter 未实施。HTML 片段与浅深色 PNG 只作布局对照，文字规范决定目标行为。

当前实现与目标的差异：

| 已读取的实现 | 对本次实现的约束 |
| --- | --- |
| `history_page.dart` 使用两排 `Row`，每个 `_stat` 都把完整字符串按同样的 20 sp 显示 | 改为两张次数卡和一张通栏汇总，不能只改字符串长度或给原时长卡固定高度 |
| `HistoryStats.calculate` 已分别提供当前周／自然月次数、所选月时长／完成组数和全部记录中的最近训练 | 继续使用同一对象，不增加累计统计或第二套数据源 |
| `AppFormats.duration()` 返回整句本地化时长；英文有独立的小时、分钟 ICU 复数 | 月度卡的视觉分层需要结构化数量与单位，不能按空格或中文词拆译文 |
| `HistoryPage` 已实现 `refreshGeneration`、`removedSessionIds`、删除结果与刷新失败的独立处理 | 仅替换展示结构，保留这些状态与现有仓储调用 |
| `AppCard`、`AppColors` 和底部导航已有共享主题与交互 | 复用既有组件及图标，不新增样式系统、主题偏好或依赖 |
| `history_stats_test` 与 `history_delete_ui_test` 已覆盖统计、删除失败、刷新失败和旧读取竞争；`focus_matrix_test` 覆盖常规历史场景 | 复用已有回归，新增能检测长时长和断行的样例；仅无 Flutter exception 不能证明没有孤立单位或错误布局 |

采用设计文档及当前代码明确的“本月＝当前自然月”定义。旧 `简单训练统计` 的“月度汇总”场景泛称该月训练次数，不据此新增所选月次数或改写顶部次数卡；本次增量用显式场景保持已确认口径。

本设计符合 schema 的条件：数字／单位分层、本地化数量表达与系统字号约束需要在实现前明确技术决策，因此保留 `design.md`。

## Goals / Non-Goals

**Goals:**

- 将布局限制在历史展示层，保持月份状态与统计计算只有一个来源。
- 在不改变既有时长精度、语言行为和读屏含义的前提下实现数值／单位分层及完整单元换行。
- 用可观察的布局、状态和语义断言补足真实长数据的回归，并区分草图与 Android 验收。

**Non-Goals:**

- 不重写仓储、数据表、主题或导航架构；不更改任何历史快照、已完成／跳过／未完成数据及其统计。
- 不为本页更改全局 `AppFormats.duration()` 的输出，也不连带重做详情、删除弹窗、训练／休息、通知或导入导出。
- 草图不成为运行依赖；不打包预览控制、示例日期、字体下载、额外图标库或开发测试入口。

## Decisions

### 1. 复用原页面状态，在同一滚动正文中替换统计区域

`HistoryPage` 仍持有 `month`、有效记录与刷新状态。使用同一 `HistoryStats` 构造次数卡、通栏汇总和列表，汇总标题与月份切换器从同一 `month` 格式化。标题、次数、汇总、最近训练、月份和列表顺序按规范固定；只有读取／刷新状态需要原有错误或进度反馈，不为顺序要求隐藏失败信息。

不增加独立 Provider、异步月度接口、统计缓存或数据库存储：数据已经齐备，另建状态会制造卡片与列表月份不一致。切月继续同步更新本页状态，不触发训练或提醒写入。最近训练仍是摘要，不新增点击或导航。

### 2. 使用历史功能内的专用展示组件

在 `history_page.dart` 内提取私有次数区域、月度汇总与时长展示组件；仅在文件规模需要时放入同功能目录。次数卡标签在上、数字在下；两卡常规等宽，同排按较高内容对齐，可采用只包住两个子项的 `IntrinsicHeight` 配合伸展的 `Row`，不为整个记录列表做内在尺寸测量。

通栏卡使用 `AppCard`。内部依次为本地化的所选月份汇总标题、训练时长标签、时长数值、分隔及完成组数横行。卡片参考 16 dp 圆角，月度数值约 32 sp、次数约 30 sp、标签／单位约 14 sp、完成组数约 20 sp；通过现有主题映射正文／辅助色与 `FontFeature.tabularFigures`，不把草图石墨色固定进页面。

不采用固定 `childAspectRatio` 的四格或固定高度卡片：两者都会让长文本与 1.6 字号受单元格尺寸限制。相邻间距复用现有 4/8 dp 体系及确认设计的参考值，实际服从内容约束。

### 3. 为月度卡增加结构化的时长呈现，保留既有整句格式

在 `lib/l10n/localization.dart` 的呈现层增加供月度卡使用的小时／分钟分量辅助方法。总小时为总秒数整除 3600，剩余分钟沿用现有算法；不足一小时时只显示分钟，整小时时仍保留零分钟。总小时不按 24 取模。该方法不改模型或存储。

视觉组件使用按当前语言格式化的数值及由 ARB 提供、按数量选择的完整单位，分别赋予数字和单位的文字角色。度量单位不是用来拼接提示句的中文片段；卡片标题、动态计数、错误及完整读屏说明继续用具名参数的完整本地化消息。中文视觉分钟可缩写为“分”，完整语义仍为“分钟”；英文保留 `hour/hours`、`minute/minutes` 的正确数量表达。新增键覆盖正式语言包并进入既有资源检查，不引入按 `localeName == 'zh'` 分支拼文案的第二套语言注册。

用 `Wrap` 安排最多两个时长单元，每个单元内部数字与完整单位同基线且禁止拆行；单元之间可换行，卡片随内容增高。完成组数行与月份标题同样允许按空间重排。使用 `LayoutBuilder` 的可用约束处理展示，不根据机型、截图宽度或固定缩放值判断。

不解析 `AppFormats.duration()` 的翻译结果，也不全局替换它：最近训练、记录摘要、详情与现有本地化测试继续使用当前完整输出。`Semantics` 提供包含指标名和完整时长的一个标签，并排除内部数字／单位的重复朗读。

### 4. 保留现有加载、空、失败及返回语义

| 页面／状态 | 处理与验收映射 |
| --- | --- |
| H01 正常记录 | 两张次数卡 → 通栏汇总 → 最近训练 → 月份 → 日期与记录；HIST-01/02、FLOW-12 |
| H03 所选月为空 | 汇总标题仍是所选月，时长／组数归零，其他统计维持；月份下显示月份空提示；HIST-02/05 |
| H05 全部历史为空 | 各项归零、最近训练暂无、月份下显示全部历史空提示；不移除已有月份操作；HIST-05 |
| 初始加载／失败 | 保留既有标题＋进度或错误重试分支，尚无有效数据时不生成假零统计；VIS-05、FLOW-16 |
| 删除成功／刷新失败 | 保留 `openDetail` 的移除缓存、代次保护及独立结果提示；只重试加载，所选月不丢；INT-09、FLOW-13/16、HIST-05 |
| H02/H04、D13 返回与取消 | 沿用原有进入详情、更多菜单删除、确认／取消、提交防重复及 Android 返回；不新增弹层或改变删除时机；HIST-06 |

### 5. 以既有正式语言、主题和安全区完成适配

新增月度标题及局部标签进入中英文 ARB，月份调用现有 `AppFormats.month` 后作为完整标题消息的参数；数量与单位保留 ICU 复数。最近训练的长用户名称、月份英文、计数标签和错误消息可换行，不改变用户内容。

H01/H03/H05 覆盖 360／430 dp × 中英文 × 浅深 × 1.0／1.3／1.6 字号；四主题色检查共享组件在各自浅深配对中可读，补充短屏、740×390 横屏、约 768 dp、长译文及减少动态效果。页面仍使用原有 `SafeArea`、滚动正文和外层底部导航，不新建覆盖正文的固定栏；月份箭头至少 48 dp。语义与键盘检查可自动化，真实 TalkBack 连续操作单独记录，不以 Widget 语义断言代替真机验收。

### 6. 用真实长数据和状态联动验证，避免仅检查样式常量

新增 `test/history_summary_ui_test.dart`，通过可控历史数据覆盖 0、59 分钟、3 小时 12 分、123 小时 45 分、整小时及单复数；检查区域先后、标题月份同步、数值完整、单元断行、卡片包围范围与读屏标签。正常渲染不抛异常只是辅助证据，不能替代几何关系和完整文本验证。

复用 `history_stats_test.dart` 的周／月边界、同日多次及删除重算，复用 `history_delete_ui_test.dart` 的取消、失败、最后删除、刷新失败和过期读取；新增场景只补足新汇总组件的联动。扩充 `focus_scenes` 或专用 fixture 提供超过一小时的历史数据，并按新文案补足 `LongStrings`，不改原统计预期迎合 UI。

## Risks / Trade-offs

- [单位分层可能破坏 ICU 复数或重复读屏] → 数量单位由正式资源决定，完整消息负责语义；测试 0、1、2 等数量及单一朗读标签，保持旧格式化接口。
- [汇总卡与下方月份选择器之间有最近训练摘要，可能误解统计范围] → 卡片始终显示所选年月，使用同一月份状态，切到历史月和空月均验证。
- [卡片增高会减少首屏记录数] → 接受完整内容需要的高度，页面可滚动；不以缩字、截断或下移汇总换取首屏数量。
- [小范围布局重构误伤刷新／删除竞争保护] → 状态与仓储逻辑保持原实现，已有受控异步测试作为必跑回归。
- [草图证据被误写为正式通过] → 运行证据单列 `docs/qa/history-summary-layout-acceptance.md`，记录平台、尺寸、字号和未验项；旧 QA 与归档内容不重写。

## Migration Plan

1. 后续用户明确要求 apply 后，仅在历史展示、本地化、相关测试及验收文档中实施；不需要数据迁移或新包，现有历史与活动训练直接继续使用。
2. 完成针对性 Widget／资源／既有历史回归，并在 Android 上核对正常、长时长、大字号和返回。更新设计入口与本设计目录的实施状态时引用实际证据，未通过项保持未完成。
3. 回退时只撤回新展示组件及其新增资源，继续使用既有统计和页面状态。无数据或偏好需要回滚；发布与主规格同步／归档由对应后续授权决定。
