# Tasks

本清单基于 [proposal.md](proposal.md)、[design.md](design.md) 和 [五个能力 delta](specs)，目标为 `focus-a-2026-10-14`。用户已明确授权按提案实施，实际进度以下方复选框及验收记录为准；按下列七阶段推进，每阶段展示可审查结果和证据，授权未覆盖下一阶段时停止。明确授权多个阶段时不重复询问已覆盖范围。

页面与 D/A/CMP 编号见[设计清单与主规范](../../../../docs/design/README.md)，INT、VIS、FLOW、ADAPT 见[交互规范](../../../../docs/design/interaction-spec.md)和[验收标准](../../../../docs/design/acceptance-checklist.md)。所有阶段沿用仓储、模型、数据库 v3、JSON v1、提醒与平台协议；新文案使用现有 ARB 和格式化层，不以改动业务规则消除 UI 失败。

每阶段在 `docs/qa/focus-a-redesign-acceptance.md` 对应章节增补实际命令、设备／主题／语言／字号、页面编号、截图和未通过项，保留旧验收记录。自动化和 Android 实测分别记录，旧 UI 或浏览器原型截图不能证明新 Flutter 验收。阶段内新增文案须执行 `flutter gen-l10n` 与 `dart run tool/check_localizations.dart`；只为可观察的行为风险增补测试，不编写样式常量镜像断言。
