# Proposal

## Why

设置页目前缺少应用介绍、实际安装版本和仓库入口，用户首次使用时也看不到隐私、本地数据及计划备份边界。补齐这些信息，并将底部“计划”的斜哑铃替换为已确认的列表图标，使产品说明与 A · 专注工具的视觉和实际离线行为一致。

## What Changes

- 在设置页底部增加“关于 SetTrace”分区，直接展示现有三线品牌标志、固定品牌名、一句话简介及实际安装版本／构建号；提供项目主页、问题反馈、第三方开源许可与“隐私与数据说明”入口。
- 第三方许可默认仅展示 Flutter、sqflite、shared_preferences、package_info_plus、url_launcher 的名称和用途，点击查看详情；次级入口保留完整离线列表，按项目合并重复许可。
- 将底部导航“计划”图标改为 `Icons.list_alt_outlined`，保留文字、入口顺序、选中态与导航行为。
- 增加首次启动的“欢迎使用 SetTrace”说明弹窗：简介、不收集或上传个人信息与使用数据、App 不主动联网、外部网页由浏览器访问、本地数据删除和计划导入导出边界。通过“我知道了，开始使用”记录已阅，不使用协议同意勾选。
- 新安装和旧版本升级后首次遇到该说明均展示一次；正常后续升级不重复展示。在关于分区可随时重看。
- 明确限制 Android 系统云备份与设备迁移中的应用私有数据，验证卸载／清除数据与公共下载目录导出文件的区别，不将系统可恢复数据描述为已彻底消失。保留开发调试需要的网络权限，正式发布产物不得含联网权限或遥测上传。
- 所有新增 UI 遵循 `docs/design` 当前 `focus-a-2026-10-14` 设计：扩展 C01/C02/C04，增加本变更局部编号 C05（关于内容）、D15（首次说明）、D16（重看说明）；沿用 CMP-01/02/04/05、INT-06/07/08/10、VIS-01–05、ADAPT-01–07。局部编号不是已发布设计文档中的既有画面。

## Capabilities

### New Capabilities

无。新增行为归入现有应用体验与本地化能力。

### Modified Capabilities

- `app-experience`：关于分区、实际版本、外部链接、第三方许可、首次已阅及重看行为、计划导航图标、本地隐私与 Android 备份约束。
- `app-localization`：新增介绍、说明、元数据及失败反馈的中英文文案、辅助语义和适配要求。

## Impact

- 预计涉及 `lib/features/settings/`、`lib/app/app.dart`、`lib/core/widgets/app_bottom_nav.dart`、新增应用信息／说明偏好服务、`lib/l10n/`、`pubspec.yaml` 与打包品牌资源；实际版本和外部链接拟采用 `package_info_plus`、`url_launcher` 的兼容稳定版本。
- Android 应用 Manifest 和备份／迁移规则需要显式配置；验证合并后的 release Manifest、安装元数据和真实浏览器跳转，不能仅凭源码断言通过。
- 实施时补充 `docs/design` 中相关页面、交互和验收描述，明确新增编号；不改已归档变更，不将新目标标为已实施。本次提案阶段只新增当前 change 的规划文件。
- 无业务数据库迁移，不改变计划默认配置、本次快照、组数／休息／参考重量、历史统计、跳过／撤销、提醒有效性或 JSON v1。计划导出仍只含计划与动作配置，不扩展成历史或全量备份。
- 不新增账号、云同步、自动更新、统计采集、远程内容或新的项目许可证；第三方许可入口展示打包依赖实际附带的许可。
