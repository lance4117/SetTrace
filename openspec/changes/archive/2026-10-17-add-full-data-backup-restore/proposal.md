# Proposal

## Why

SetTrace 当前仅能导出计划配置，长期积累的训练历史没有可由用户主动保存、换机恢复的完整备份。新增独立的完整备份与恢复流程，并定义长期格式兼容、恢复前保护和撤回规则，避免卸载、换机或误恢复导致记录丢失。

## What Changes

- 设置顺序调整为「外观 → 主题色 → 语言 → 适用休息提醒 → 数据 → 关于 SetTrace」；数据分区提供「备份与恢复」单一导航行，进入独立页面（B00/B01）。
- 全量导出全部计划、动作配置、已保存训练的完整快照与可迁移设置，生成公共 Downloads 中的独立文件；提供真实导出状态和此后数据变化提示。空数据也可备份。
- 新增与计划分享分离的 `settrace.user-backup` 版本化格式。兼容性由备份格式版本决定，与应用版本、SQLite 版本分别管理；新版保留旧备份读取与转换能力，不支持的未来格式整份拒绝。
- 恢复前完整校验并预览；已有数据和空设备均可恢复。一次明确确认后，先持久保存并验证恢复前副本，再原子替换全部计划和已保存历史；不合并、不按条目挑选、不默默跳过错误内容。
- 失败保留当前数据；核心数据已提交、设置恢复失败、页面刷新失败分别呈现和重试。进程中断后核实持久化结果，不重复执行恢复。
- 恢复后可撤回。撤回也先保护当下数据，包含恢复后新增的记录；副本冷启动后仍可管理、导出和逐份确认删除，不自动过期。应用内副本与卸载后保留的外部文件明确区分。
- 将现有 UI 草案的推荐默认值纳入本提案：活动训练先由用户按原流程处理；恢复设置默认勾选、可取消；保护副本不自动清理；暂不提供后台自动备份、账号、自动同步、合并、加密备份或 CSV 分析导出。
- 更新首次／可重看的数据说明，区分计划分享、完整备份、应用内副本和 Android 系统迁移；提高独立说明版本，使已阅读旧范围说明的用户能看到新说明。
- UI 必须遵循 `focus-a-2026-10-14`（A · 专注工具）及现有四主题色增量，复用 CMP-01–05；采用备份设计 B00–B20、其子状态及 E01–E14，覆盖两语、浅深、长文案、字号、返回、错误和辅助输入。数量、时间、文件大小等原型示例不是实现默认值。

## Capabilities

### New Capabilities

- `data-backup`：完整备份格式、内容与历史保真、版本迁移、文件输出与校验、覆盖恢复、操作中断、保护副本及撤回。

### Modified Capabilities

- `app-experience`：设置数据入口、备份页面与状态、离线可用范围、提醒分区顺序、首次／数据说明及隐私边界。
- `app-localization`：备份与恢复全流程的中英文、动态数据、辅助语义及更新后的数据说明。

`training-plans`、`workout-session`、`workout-history` 的现有业务含义不变；新能力引用其保存、统计、结束和计划分享规则，不复制或改写这些主规格。

## Impact

- Flutter：新增 `lib/features/backup/`；接入 `settings_page.dart`、`lib/app/app.dart`、启动恢复检查、主题／语言和提醒设置；使用既有主题、按钮、卡片与 ARB。
- 存储：沿用 SQLite 为实时业务数据源；从数据库 v4→v5 增加备份操作／副本索引／导出状态元数据，再以 v5→v6 增加计划 sort_order 和历史 backup_order，以保留备份数组顺序与原时间；旧版按原查询顺序初始化，新建与导入追加到末尾，不重建原业务表、不更改训练字段含义、不为未来同步迁移全局 UUID。正式格式独立于数据库表结构。
- Android：独立的完整备份文件桥接，采用文件流／暂存文件，不沿用计划传输的 2 MiB 限制或整段字符串通道；原生提醒读取器当前只接受数据库 v4，必须随增量迁移明确支持 v4/v5/v6，并验证旧通知和恢复竞争。
- 恢复需在仓储层串行化写入、等待已发起的偏好保存、使过期页面／请求失效；SQLite 与 SharedPreferences 不能假设共同原子提交，设置使用独立可重试阶段。
- 依赖保持离线；如摘要实现需要新增 Dart `crypto`，仅用于本地完整性核验，不引入账号、联网权限或服务 SDK。
- 更新备份格式文档、当前设计文字的设置顺序／数据说明及独立 QA 记录；保留既有计划 JSON v1、2 MiB 规则、新增副本语义和所有既有归档／验收证据。
- UI 依据：[设计入口](../../../../docs/design/README.md)、[主规范](../../../../docs/design/SetTrace_UI_Design_System_and_Flutter_Spec.md)、[页面状态](../../../../docs/design/screens-and-states.md)、[交互](../../../../docs/design/interaction-spec.md)、[验收](../../../../docs/design/acceptance-checklist.md)、[备份 UI](../../../../docs/design/backup/backup-ui-spec.md)。重点对齐 C01/C02/C04/C05、X01–X04、H01–H05、D15–D19、INT-02/07–12、VIS-01–05、ADAPT-01–07、BK-FLOW-01–07 与 BK-DATA-01/02。

本变更已获授权实施；顺序持久化补充于 2026-10-17 经用户确认，完整验收仍在进行。现有 HTML 核验不构成 Flutter、迁移、文件恢复或真机验证通过。
