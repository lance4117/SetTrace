## 4. 训练状态与休息逻辑

- [ ] 4.1 实现从计划到会话快照的一次事务创建及已有会话拦截；用测试验证新会话顺序、组数、两类休息与来源计划一致，第二场不会覆盖第一场。
- [ ] 4.2 实现“完成本组”的原子状态转换和连点保护；用测试覆盖组间、动作间、全场最后一组及重复提交，验证一组只记录一次时间。
- [ ] 4.3 实现基于绝对截止时间的休息、±30 秒、跳过和到期转换；用可控制时间的测试验证后台经过时间及重启后的剩余时间。
- [ ] 4.4 实现撤销最近一组和本次目标组数/后续休息配置修改；用测试验证游标、组行、休息清除、不能减到已完成数以下，以及原计划未变化。
- [ ] 4.5 实现结束确认后的部分保存、零组丢弃和显式丢弃；用测试验证结束时间、实际时长、历史可见性与未确认时数据不变。
- [ ] 4.6 实现应用启动/恢复时查询并归一化未完成会话；模拟进程重启和过期休息，验证可继续原动作且已完成组未丢失。
