# Proposal

## Why

训练本目前只有 OpenSpec 初始化、设计说明和高保真参考图，尚无 Flutter 工程。第一版需要把“选择计划、逐组完成、休息、恢复训练、查看历史”连成一个可靠的离线闭环，尤其要避免后台切换或误触造成记录丢失。

## What Changes

- 建立以 Android 为首要目标的 Flutter 应用，提供计划、记录、设置三个主入口，以及训练准备、训练中和休息中的页面状态。
- 支持自定义训练计划及动作的创建、改名、删除、排序；动作配置包括默认组数、组间休息、动作后休息，以及可选默认重量。休息按 30 秒步进。
- 开始训练时复制计划配置作为本次快照。每组只记录完成状态和完成时间；“完成本组”是主要操作。支持休息跳过、±30 秒、撤销、修正本次训练和提前结束。
- 将进行中的训练及绝对休息截止时间持久化，App 进入后台或进程重启后可继续。
- 保存训练历史，按日查看训练内容，提供本周、本月训练次数、最近一次训练及简单时长和组数汇总。
- 按高保真浅色/深色稿建立共享的语义色与组件；训练页保持大组数、大计时、单手可达的主操作。
- 对设计稿中尚无可靠计算依据的“预计训练时长”暂不展示估算值；补上完整动作列表入口、明确的结束训练操作、本周统计及记录详情。

## Capabilities

### New Capabilities

- `training-plans`: 自定义计划与动作配置、管理和排序。
- `workout-session`: 本次训练快照、逐组记录、休息计时、纠错和状态恢复。
- `workout-history`: 完成记录、按日查看和简单统计。
- `app-experience`: 页面导航、浅色/深色主题及训练场景易用性。

### Modified Capabilities

无；当前没有既有 OpenSpec 能力规格。

## Impact

- 新建 Flutter/Dart 与 Android 工程；核心数据保存在设备本地 SQLite，不要求账号、网络或后端。
- 新增计划、动作、训练会话、会话动作快照、按组完成记录等本地数据及迁移规则。
- 视觉参考为 `docs/design/SetTrace_UI_Design_System_and_Flutter_Spec.md` 及同目录的 High-Fi Light、High-Fi Dark、Design Tokens 图片。产品需求优先于示意内容。
- 第一版不包含云同步、通知、社交、课程、AI 建议、饮食和复杂健身分析。
