# 存储、控制与恢复

生产目录为 Android `noBackupFilesDir/diagnostics`，独立于业务SQLite、备份协调器和Flutter引擎。文件创建、控制读写和清理均在原生后台执行器；应用级入口只创建运行时并提交任务。

| 范围 | 上限 | 处理 |
| --- | --- | --- |
| 普通事件 | 16 MiB，段≤1 MiB | JSONL，最旧可清理段先轮转 |
| incident | 4 MiB，段≤512 KiB | 单份帧级堆栈≤32 KiB、指纹去重 |
| 合计日志 | 20 MiB且最多7×24小时 | 详细模式共用，容量先到缩短覆盖 |
| 辅助文件 | ≤1 MiB | 控制≤16 KiB，单任务journal≤64 KiB；原子替换临时／备份文件计入 |
| 导出staging | ≤24 MiB | 单任务流式ZIP，无全量源文件复制 |
| 队列 | 总预算≤1 MiB | Dart128 KiB、原生缓冲512 KiB、跨层入口128 KiB；记录数亦受限，保守计入字符串和容器副本 |

分段头描述版本、代际、保留时刻和开机／单调边界。索引由有界扫描重建并缓存在内存，不额外持久化业务表或依赖索引文件；末行损坏保留合法完整前缀，损坏、不可读和未知版本如实报告。导出再次验证字段，不复制未校验日志字节。

同一开机边界用单调时间判断年龄；跨开机使用墙上时间和最近有效锚点，回拨后无法证明仍在保留期的旧段保守排除。启动、轮转、控制、导出执行清理，停用期间不为日志唤醒设备。七天不是连续覆盖承诺。异常风暴保留首次线索，60秒内同指纹聚合次数；提交事实不采样。

## 控制状态

控制文件首次确实不存在才常规开启。已有损坏、不支持或不可读状态暂停记录，不恢复默认开启。原子替换先准备，再以备份恢复协议提交；失败保持上一确认值。

关闭总开关后，原生和Dart停止新操作／异常记录，缓冲被清理，详细期限失效；旧日志按保留规则清理，主动环境导出仍可用。再次开启只恢复常规模式。详细期限只驻留当前进程，以单调时间限制30分钟，重启不恢复。

清空先提交新代际和意图，再删除旧段与私有staging，成功结束意图；旧事件不能按新代际重写。部分删除失败保留残留字节和真实失败，重启或重试继续核查；总开关保留，公共文件、训练与备份不在删除范围。清空不结束当前有效详细模式，关闭记录才停止它。

导出源引用最多固定30秒，固定文件计入日志总预算；容量不足时丢弃并计数，不越界。整个导出未结束时清空返回busy，需先完成或取消。公开发布结果未知时先核查，不以清空私有日志删除公共文件。

## 格式升级与回退

诊断schema、控制和ZIP版本独立于业务SQLite v6及完整备份格式1。不支持的控制版本暂停记录；未知日志版本不原样导出，仍受容量和时间清理。旧版不具备清理器时不承诺继续七天清理；回退前应停用／清空或说明私有残留，不删除用户业务或公共文件。

组件测试为 `DiagnosticsContractTest`、`DiagnosticsStoreTest` 和Dart诊断契约测试。真实平台目录、无引擎运行、Download与发布权限另由Android验收记录证明。

## 双版本和进程构建

事件和分段支持 1／2，段内版本必须一致，版本变化创建新段；保留、轮转、关闭和清空沿用原规则。
控制协议仍为 1，控制文件额外保留最多 32 个进程的安装 version/build 映射，仍限 16 KiB／总辅助 1 MiB。
映射来源是该进程实际安装信息；Dart 批次只登记当前内存进程身份，不重标历史事件。
超出映射容量或升级前缺失时只标未知；清空删除旧映射，新代际可登记当前进程。
旧应用不能保证理解新日志；不得为回退重置业务数据、诊断开关或系统静音。
